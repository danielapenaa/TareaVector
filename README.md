ARCHIVO README DE TAREA VECTOR 
## Objetivo

Desarrollar un programa en Java que permita trabajar con un vector de 15 números enteros, aplicando estructuras de control y ciclos para ingresar y validar los datos, buscar valores, identificar el número mayor y menor, encontrar múltiplos, calcular la suma y el promedio, y crear un nuevo vector con los valores que se encuentran por encima del promedio.
